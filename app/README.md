# 🤖 AI Customer Support Agent

An AI-powered customer support chatbot built using **LangChain, RAG, ChromaDB, FastAPI, and OpenAI**.

The system allows users to ask questions and receive intelligent answers from a custom knowledge base.

## 🚀 Features

- 📄 PDF document understanding
- 🔎 Retrieval Augmented Generation (RAG)
- 🧠 LangChain integration
- 🗂️ Chroma vector database
- 🤖 AI-powered responses
- 🌐 FastAPI backend
- 💬 Modern chat interface
- ⚡ Real-time question answering
- 🛡️ Error handling

## 🛠️ Technologies

- Python
- FastAPI
- LangChain
- ChromaDB
- HuggingFace Embeddings
- OpenAI API
- HTML
- CSS
- JavaScript
