# 🎤 Voice AI Assistant

A Voice AI Assistant built with Python and FastAPI.

## Features

- 🎤 Voice Recognition (Whisper)
- 🤖 AI Chat (OpenAI GPT-5 Nano)
- 🔊 Text-to-Speech
- 🌐 Open Websites
- 💻 Open Applications
- ▶️ Search YouTube
- 🕒 Current Time
- 📅 Current Date
- 📷 Take Screenshot
- 📴 Shutdown Computer
- ❌ Cancel Shutdown
- 💬 Conversation Memory
- 📝 Chat History

## Technologies Used

- Python
- FastAPI
- OpenAI API
- Whisper
- SpeechRecognition
- pyttsx3
- HTML
- CSS
- JavaScript
